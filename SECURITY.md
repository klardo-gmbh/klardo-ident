# Security

**Email security@klardo-ident.com.** Please do not open a public issue for a
security problem, in this repository or anywhere else.

Tell us what you found, how to reproduce it, and which version you were running.
We will confirm receipt, keep you updated while we work on it, and credit you in
the release notes if you would like that.

This repository holds deployment files. Vulnerabilities in **KlardoIdent itself**
belong at the same address — it is the right one for both.
